# 食事管理アプリ 要件定義書

## 1. 目的

カロリーとPFC（たんぱく質・脂質・炭水化物）を中心に、日々の食事を短時間で記録・確認・再利用できるスマートフォンアプリを作る。記録データは期間を指定してCSV出力できるようにする。

## 2. MVPの範囲

- iOSとAndroidに対応する
- 個人が1台の端末で利用する
- アカウント登録、ログイン、クラウド同期は行わない
- データは端末内に保存する
- カロリーとPFCの目標値はユーザーが設定する
- 食品検索、バーコード、写真解析、AI推定は対象外とする

## 3. 機能要件

- 日付を切り替え、選択した日の食事記録を確認できる
- 選択した日の摂取カロリーとPFCを集計し、目標値と比較できる
- 食事区分、食品・料理名、PFC、カロリー、メモを入力して食事を記録できる
- PFCからカロリーを自動計算できる
- カロリーを手動でも入力できる
- 登録した食事を編集・削除できる
- よく使う食品を登録・編集・削除し、食事記録へ再利用できる
- 複数の食品をセットとして登録・編集・削除し、食事記録へ一括追加できる
- 1日分のカロリーとPFCの目標値を設定できる
- 期間を指定して食事記録をCSV出力できる
- 食事記録、よく使う食品、セット、目標値を端末内に保存できる

## 4. 非機能要件

- スマートフォンで利用できる
- オフラインで主要機能を利用できる
- 保存したデータを利用者の操作なく外部へ送信しない
- 日常的な記録操作を短時間で完了できる

## 5. UIプロトタイプ

画面構成、画面遷移、基本的なデザインは `prototype/` を参照する。要件定義書とプロトタイプに矛盾がある場合は、この要件定義書を優先する。
