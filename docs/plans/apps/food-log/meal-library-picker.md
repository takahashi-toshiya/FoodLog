# 食事追加時のライブラリ選択 実装計画

## 目的

食事追加画面からライブラリ食品を選択できるようにする。また、食事記録とライブラリ食品の追加・編集を文言から判別できるようにする。

## 実装範囲

- 食事追加画面に「ライブラリから選ぶ」導線を追加する
- 一覧・検索・選択だけを行う食品選択モーダルを追加する
- 選択した食品の名称、PFC、カロリー、メモ、食品IDを食事入力へ反映する
- 選択前の日付、食事区分、摂取倍率を維持する
- 食事記録とライブラリ食品の追加・編集画面について、タイトルと保存ボタンの文言を区別する
- 既存のライブラリ管理画面から食事へ追加する導線を維持する

## 仕様

- 食品選択モーダルでは食品の追加・編集・削除を提供しない
- 食品選択後はモーダルを閉じ、食事追加画面で内容を確認・変更できる
- ライブラリからカロリーは引き継がず、反映したPFCから自動計算する
- 利用者が明示的に切り替えた場合だけ、カロリーを手動入力できる
- 食事を保存しても、参照元のライブラリ食品は変更しない
- 食品一覧の取得中、0件、検索結果0件、取得失敗を区別して表示する
- 取得失敗時は再読み込みできるようにする

## 起こり得る問題

- 食品選択によって、入力済みの日付や食事区分まで初期化される
- 食品選択後の食事保存が、参照元のライブラリ食品を更新する
- 食品選択画面に管理操作が混ざり、操作目的が曖昧になる
- 取得失敗後に選択画面から戻れなくなる
- 文言変更によって既存テストやアクセシビリティラベルが実態とずれる

## テスト・確認

- 食事追加画面から食品選択モーダルを開ける
- 一覧を検索し、食品を選択できる
- 選択した食品情報が入力欄へ反映される
- 選択前の日付、食事区分、摂取倍率が維持される
- 反映後に値を変更して食事として保存できる
- 保存時に食品IDが記録され、ライブラリ食品は更新されない
- 選択画面に追加・編集・削除操作が表示されない
- 4種類の追加・編集画面で操作対象が文言から判別できる
- 既存の直接入力とライブラリ管理画面からの食事追加が動作する
