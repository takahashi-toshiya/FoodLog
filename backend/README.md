# FoodLog Backend

FoodLogのREST APIを提供するNestJSバックエンドです。

## 必要な環境

- Node.js 22.12以上
- npm

## セットアップ

```bash
npm install
```

## コマンド

```bash
npm run start:dev    # 開発サーバー
npm run format:check # フォーマット確認
npm run lint         # 静的解析
npm run typecheck    # 型チェック
npm test             # テスト
npm run test:e2e     # E2Eテスト
npm run build        # ビルド
```
